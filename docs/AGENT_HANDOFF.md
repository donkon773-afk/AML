# Передача агенту: AML NAM выпуск r2 (24.09.2026)

Пакет `aml-nam-r2` развивает AML/NAM как компактный протокол межагентного обмена (A2A wire protocol) для кластера агентов и локальных моделей.

## С чего начать

1. Прочитайте `README.md`, `docs/CLUSTER_GUIDE.md` и `docs/COMPATIBILITY.md`.
2. Установите зависимости и проверьте тестовый контур:
   ```sh
   python -m pip install -r requirements-test.txt
   npm ci
   python verify.py
   ```
   Результат должен быть: `OFFLINE PASSED` (116 тестов Python, 14 тестов JS, GBNF check, demo; 0 ошибок, 0 пропусков).
3. Для проверки работы с локальными моделями изучите `review/2026-09-24/LIVE_FRAMES.md` (200 запросов на qwen3.5-9b и gemma-4-12b-coder).

## Ограничения и правила

1. **Не смешивать профили**: фреймы кластера обязаны содержать `s:2` в заголовке; военный словарь не допускается в `s:2`.
2. **Модели не меняют доску напрямую**: вердикты моделей (`RES`) регистрируются как советы; статусы меняют только авторизованные агенты кластера.
3. **Разделитель сообщений**: фреймы в outbox отделяются пустой строкой (`\n\n`).
4. **Безопасность**: приёмник проверяет свежесть (TTL 60 с), ревизии, полномочия по `board.json` и защищён от повтора.
